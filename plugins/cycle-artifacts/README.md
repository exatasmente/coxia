# Cycle documents / Documentos do ciclo

**English.** This folder ships with the app: a declaration with no code and nothing to reach. It names the three
documents the cycle's flow writes as part of the work — `REQUIREMENTS.md` (refinement, read at gate 1), `PROTOTYPE.md`
(plan, read at gate 2) and `USER_MANUAL.md` (the stage that closes the run, beside the release note). Each one says
where it lands in the card's phase order (just above a file the cycle already counts) and which gate reads it. It comes
on by default; the person switches it off in the plugins list, and a copy of the same `id` in the workspace's own plugins
folder wins over this one. What each document contains is decided by the flow, not here.

**Português.** Esta pasta vem com o aplicativo: uma declaração sem código e sem nada a alcançar. Ela nomeia os três
documentos que o fluxo do ciclo escreve como parte do trabalho — `REQUIREMENTS.md` (refinamento, lido no gate 1),
`PROTOTYPE.md` (plano, lido no gate 2) e `USER_MANUAL.md` (a etapa que fecha a execução, ao lado da nota de lançamento).
Cada um diz onde entra na ordem de fase do cartão (logo acima de um arquivo que o ciclo já conta) e qual gate o lê. Vem
ligado por padrão; a pessoa o desliga na lista de plugins, e uma cópia do mesmo `id` na pasta de plugins do workspace
vence esta. O que cada documento contém é do fluxo, não daqui.
