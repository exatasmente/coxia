- A checagem de línguas nomeia o par pela forma que o site escreve: pasta `pt-br/` para páginas escritas à mão, marca `.pt-br` e endereço `/reference/…` para páginas geradas. A página cujo par existe ao lado passa sem link próprio (a navegação leva); um link que leva a uma página que não é o par reprova.
- Um documento de português com o inglês sob um segundo título (`# … (English)`) vira duas páginas (`blocksOf`); um documento de uma língua só continua uma página.
- **Páginas de referência são julgadas pelo documento, não pelo gerado.** Um documento bilíngue que perde a metade em português é escrito pela construção como página de uma língua só, com a marca `site: one-language`, indistinguível do gerado de um documento que sempre teve uma língua. A checagem decide pela declaração do **índice de `docs/`** (a coluna de línguas da tabela): documento declarado bilíngue exige a página inglesa sem a marca, com o link de par e o arquivo `.pt-br` presente; declarado em uma língua só não exige par.
- **`otherLanguageLink` lê as duas formas do link de língua**: o HTML (`<a href title="Português">`) das páginas escritas à mão e o Markdown (`[Português](/reference/x.pt-br "Português")`) que a construção escreve nas páginas geradas.

- Exigir o link que leva de uma língua para a outra nas páginas escritas à mão: permanece sugestão, não coberta.
