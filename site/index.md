# Coxia

**Walk into stand-up already prepared, and leave with the follow-ups done.**

Coxia is a desktop app, with a phone companion, that gets a developer through the recurring
rituals of a team — by voice or by text. One agent per open task reads the repository, the specs
and the documentation you point it at before it says a word, helps you unblock the thing you are
stuck on, and hands you the minutes. Nothing outside your machine changes without your explicit
yes.

[Install it and get to a first ceremony](/guide/) — or read what it does below.

## What it does

- **A ceremony in seconds.** Stand-up, planning, retro: the app calls the agents you keep for
  each role, they read before they speak, and the minutes are written as you go.
- **A fleet of agents over the cycle.** An open task goes through triage, refinement, plan,
  development, review and QA, each stage worked by an agent of your team, with a gate for you
  wherever the process asks for a decision.
- **Nothing leaves without you.** Reading the code host is open; what is written to it — a comment,
  a review, a branch push, a pull request — is proposed and waits for your yes.
