# Casos de uso

Quatro situações inteiras, do lado da pessoa. Cada uma diz o que o aplicativo faz e o que fica com
você.

| Caso de uso | A situação |
|---|---|
| [Uma pessoa e um time de agentes](/use-cases/pt-br/team) | Um único mantenedor conduz um projeto com agentes em cada papel recorrente. |
| [De uma issue ao pull request](/use-cases/pt-br/issue-to-pr) | Uma execução inteira, da triagem a um pull request esperando um "sim". |
| [Um login numa tela virtual](/use-cases/pt-br/screen) | Um agente entrega a tela à pessoa para um login que ele não deve ver. |
| [O celular pareado aprova](/use-cases/pt-br/phone) | A pessoa decide um gate, ou diz sim a um envio, pelo celular. |
