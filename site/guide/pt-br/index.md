# O guia

Quatro passos, na ordem. Cada um diz o que você deve ver no fim dele.

| Passo | Aonde ele leva |
|---|---|
| [Instalar](/guide/pt-br/install "Instalar") | O aplicativo rodando na sua máquina. |
| [O primeiro espaço de trabalho](/guide/pt-br/workspace "O primeiro espaço de trabalho") | O aplicativo apontado para um repositório, com um modelo com que ele consiga falar. |
| [A primeira cerimônia](/guide/pt-br/ceremony "A primeira cerimônia") | Uma daily conduzida por voz ou texto, com a ata escrita. |
| [A primeira execução](/guide/pt-br/run "A primeira execução") | Uma issue pelo ciclo de agentes, até um pull request esperando o seu "sim". |

Se preferir ler o manual primeiro, a [referência](/reference/index) é a mesma documentação que os
agentes do próprio aplicativo leem, e é uma página deste site.
