- Aceite: a tela de execuções lista issues abertas com o rótulo de gatilho e sem responsável, com um jeito de iniciar um run à mão; nada inicia por si mesmo a partir dessa lista.
- A varredura automática usa `triggered(label)` via `listMyIssues`; issues com o rótulo e sem responsável nunca entram nela. A varredura não muda.
- A issue de origem da divisão cobre só documentação e a dica do campo de gatilho — não sobrepor.
- Regras do projeto: textos via `t()` nos dois catálogos; sem número real de issue em arquivo do repositório público (usar `#123`); inglês em código e commits; mudança visível ao usuário exige linha de CHANGELOG sob `## [Unreleased]`.

- Evidências e rascunhos ficam fora da worktree; o que fica nela entra no commit da etapa.
