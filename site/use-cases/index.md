# Use cases

Four situations, whole, from the person's side. Each one says what the app does and what stays with
the person.

| Use case | The situation |
|---|---|
| [One developer, a team of agents](/use-cases/team) | A single maintainer runs a project with agents in every recurring role. |
| [From an issue to a pull request](/use-cases/issue-to-pr) | A whole run, from triage to a pull request waiting for a yes. |
| [A login on a virtual screen](/use-cases/screen) | An agent hands the screen to the person for a login it must not see. |
| [The paired phone approves](/use-cases/phone) | The person decides a gate, or says yes to a push, from the phone. |
