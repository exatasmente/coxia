# Release Note

This version adds three new documents to the cycle folder to support prototyping and requirements engineering:
- REQUIREMENTS.md: produced after refinement, contains the requirements for the cycle.
- PROTOTYPE.md: produced after planning, contains the prototype for the cycle.
- USER_MANUAL.md: produced at the end of the cycle, alongside this release note, contains the user manual for the cycle.

These documents are generated automatically as the cycle progresses and are versioned with the cycle.

No action is required from the user. The documents will appear in the cycle folder as the cycle advances.
